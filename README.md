# 🌐 Aditya Singh — Aspiring AI Engineer Portfolio

This is my official personal portfolio website built using modern frontend tools like **React**, **Tailwind CSS**, and **Framer Motion**. ## 🚀 Tech Stack

- ⚛️ **React.js** – For building reusable UI components
- 🎨 **Tailwind CSS** – Utility-first CSS framework
- 🧠 **Framer Motion** – Advanced animations and transitions
- 🔁 **Lenis Scroll** – Smooth scrolling experience
- 📦 **React Toast** – Toast notifications
- 🧩 **React Icons** – Icon library integration
- ⚡ **Vite** – Lightning-fast build and development tool
